# Amiro Tutoring — V2

V2 is the personalized, founder-led version of the Amiro Tutoring website.

## Files
- `index.html` — website content and structure
- `styles.css` — design, layout, typography, responsive behavior
- `script.js` — mobile navigation
- `assets/ameer.jpg` — Ameer founder photo
- `assets/audria.jpg` — Audria founder photo

## Current state
- Real founder photos and biographies are included.
- Programs reflect the subjects Ameer and Audria currently feel comfortable teaching.
- Main CTA uses `info@amirotutoring.com` and a pre-filled consultation email.
- Pricing is intentionally not displayed yet; pricing will be finalized separately.
- A full consultation form/lead system will be added in a later step.
- Google Workspace logo/footer branding will be completed after final brand polish.

## Deploying to GitHub Pages
Replace the current V1 files in the `amirotutoring.com` GitHub repository with these V2 files, keeping the same filenames and folder structure. GitHub Pages will publish the update automatically.
